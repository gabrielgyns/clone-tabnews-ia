# clone-tabnews-ia

Clone do [TabNews](https://www.tabnews.com.br), uma comunidade de conteúdos sobre programação e tecnologia, construído com auxílio de IA.

## Stack

- Next.js com App Router (rotas em `app/`)
- React
- TypeScript

Versões exatas ficam no `package.json`.

## Comandos

- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build de produção
- `npm start`: servidor de produção

## Convenções

- Manter o código simples e mínimo, seguindo as convenções modernas do Next.js.
- Textos da interface em português (pt-BR).
